# Папа Кедр — конфигуратор бани (пилот)

3D-конфигуратор двух моделей бань для клиента «Папа Кедр» (папа-кедр.рф).
React + three.js (React Three Fiber), без серверной части.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # статическая сборка в dist/
```

## Модели

| Модель | Основа | Длины | Особенности |
| --- | --- | --- | --- |
| **Квадро** — стационарная квадробочка | бетонные блоки с ложементами по форме корпуса | 3–6 м | вход с торца, окна в длинной стене |
| **Мобиль** — баня на прицепе | двухосный прицеп, опорные домкраты, стяжки | 4–5 м | вход сбоку, выносная топка печи в каменной нише |

Обе модели собраны по референс-фотографиям клиента. Сайт папа-кедр.рф во время
разработки был недоступен из среды сборки, поэтому:

- **цены — оценочные.** Все цены в одном файле: `src/data/catalog.ts`. Пока
  `PRICES_PRELIMINARY = true`, итог подписан как «предварительная стоимость»;
- **характеристики** берутся из геометрии модели (габариты, площадь) и выбранных
  опций. Паспортные данные клиента (утеплитель, комплектация печи, вместимость)
  нужно внести перед запуском.

## Опции

Длина, покрытие фасада (натуральное масло / орех / графит / чёрный уголь), форма
и цвет гибкой черепицы, тип печи (дровяная, дровяная с выносной топкой,
электрическая — меняет дымоход и нишу), количество окон, фасадная подсветка.
Режимы «День / Вечер», ракурсы камеры. Конфигурация хранится в адресе страницы —
ссылкой можно поделиться.

Заявка: пока нет адреса CRM, текст заявки с конфигурацией копируется в буфер.
Для отправки укажите `LEAD_ENDPOINT` в `src/ui/RequestDialog.tsx`.

## Как устроена графика

**Геометрия** строится процедурно и точно повторяет конструкцию, без
низкополигональных упрощений:

- каждая доска обшивки — отдельное тело со своей толщиной и фасками, изогнутое по
  профилю корпуса, с зазорами и мембраной за ними (`src/three/parts/shell.ts`);
- каждый лепесток гибкой черепицы — отдельный изогнутый по дуге кровли элемент
  с толщиной; ряды перекрываются и приподняты, конёк закрыт коньковой черепицей
  (`roof.ts`);
- двери на Z-обвязке с кованными петлями и болтами, окна с наличниками, отливом,
  створкой и стеклопакетом, выносная топка с дверцей, стеклом и зольником
  (`openings.ts`);
- сэндвич-дымоход с мастер-флэшем и зонтом, прицеп с рессорами, колёсами
  (профиль шины, протектор, диск, гайки), сцепкой, домкратами, фонарями
  (`base.ts`).

Сцена — 140–260 тыс. треугольников; материалы сведены в один draw call каждый.

**Текстуры** — PBR-наборы (цвет, нормали, шероховатость/AO), которые
запекаются на GPU при загрузке (`src/three/textures/`): древесина 4096×1024
(≈1700 px на метр) с годичными кольцами, волокнами, порами и сучками,
минеральная посыпка черепицы, бетон, камень, шлифованная сталь, протектор.
Карты нормалей считаются аналитически из высот, все текстуры бесшовные, с
mip-картами и анизотропной фильтрацией. Каждая доска получает своё смещение
текстуры и оттенок, поэтому рисунок не повторяется.

Освещение — студийное HDRI-окружение (CC0, `@pmndrs/assets`, без внешних CDN)
с софтбоксами для бликов на металле, солнце с тенями 4096², ambient occlusion
(N8AO), тон-маппинг Khronos PBR Neutral. Вечерний режим включает свет в окнах,
огонь в топке и подсветку.

Параметр `?static` в адресе включает отрисовку по требованию (для
автоматических скриншотов на машинах без GPU).

## Структура

```
src/data/        каталог, цены, расчёт
src/state.ts     состояние и синхронизация с адресом страницы
src/three/       сцена, материалы, геометрия, детали моделей
src/ui/          панель конфигуратора и форма заявки
```
